# OpenGTD UI

Interface do OpenGTD, um app de tarefas para o celular feito com HTML, CSS e JavaScript puros, sem framework.

Faz parte do projeto de **TADS2024**, na matéria de **Extensão 3**.

## O que é GTD

GTD (*Getting Things Done*) é um método de organização pessoal criado por David Allen. A ideia é tirar as tarefas da
cabeça e colocá-las num sistema confiável:

1. **Capturar** tudo o que precisa ser feito.
2. **Esclarecer** o que cada item significa e qual é a próxima ação.
3. **Organizar** cada item no lugar certo.
4. **Revisar** o sistema com frequência.
5. **Fazer** a próxima ação.

Com tudo anotado, a cabeça fica livre para fazer em vez de lembrar.

## Como rodar

O app conversa com a API do OpenGTD em `http://localhost:8080` (o endereço fica na `const API`, no topo do
`script.js`). Com a API no ar, abra o `index.html` no navegador.
